# 彩票智析

原生 Android 彩票统计与智能选号项目，当前支持双色球、超级大乐透、福彩3D、排列三和排列五的规则选号（Kotlin、Jetpack Compose、SQLite）。

## 功能

- 首页：双色球/大乐透/福彩3D/排列三/排列五切换；按当前彩种生成并固定展示本期 AI 集成候选，提供 6 种主题色、开奖信息和 1–10 组快速生成。
- 数据分析：红球频率榜、冷热号分层、遗漏排行、和值走势图、红球遗漏走势图、和值/跨度/奇偶/大小/连号特征。
- 历史数据：30/50/100 期列表、1/3/5 年范围、按年份过滤、期号或日期搜索、官方数据同步。
- 智能选号：1–10 年数据窗口；综合、热号优先、冷热搭配、均衡、近期趋势、遗漏反转、分区均衡和 AI 集成等 8 种策略；和值、奇偶、大号比例和连号上限筛选；双色球历史滚动回测和命中数分布。
- 本地 SQLite 保存历史数据，启动时导入随包历史数据；联网时每 12 小时后台检查更新，也可手动同步。

## 数据来源与验证

双色球历史数据取自[中国福利彩票发行管理中心](https://www.cwl.gov.cn/ygkj/wqkjgg/ssq/)公开开奖查询接口。项目内置数据文件 `app/src/main/assets/ssq_history.json.gz` 于 2026-11-08 获取，包含 2,085 期（2013-01-01 至 2026-11-05），每期校验 7 位期号、6 个不重复的 1–33 红球和 1 个 1–16 蓝球。应用手动/后台更新时增量读取官网最近 100 期并按期号 upsert。其他彩种目前支持规则选号，官方历史数据尚未接入，历史分析和回测不会套用双色球数据。

本数据包覆盖近 10 年使用窗口；不包含 2013 年之前的完整历史。官网接口响应范围变化时，随包数据和同步数据应再次校验。

## 模型说明

模型组合历史频率、近期出现、遗漏、和值、奇偶与跨度、蓝球频率、连号结构生成候选。AI 集成是应用内的多因子启发式集成评分，不调用在线大模型，也不是训练型机器学习模型。分数是结构评分，不是中奖概率。历史回测按期开奖顺序滚动，每个目标期只用此前数据；随机抽样本身存在波动，回测不能证明未来有效。彩票具有随机性，请理性参与。

## 构建

1. Android Studio 2026.2.2 打开项目。
2. 使用 Gradle 9.6.0 和 Android SDK Platform 36（项目 wrapper 已固定 Gradle 版本）。
3. 运行 `app` 配置，或在 Windows 执行 `gradlew.bat :app:assembleDebug`。
4. 网络更新依赖 Android `INTERNET` 权限；离线首次启动使用内置历史数据。
